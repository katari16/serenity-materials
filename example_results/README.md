# Reference run outputs

Figures and numerical summaries from the bundled quick and full experiments, executed with the installed wheel in a separate Python 3.12.3 environment. Run `python scripts/reproduce.py --full` to regenerate the numerical arrays, CSV tables, meshes, and figures. Run `python scripts/reachable_workspace.py --config workspace_quick` for the quick surface. `run.json` records the machine and dependency versions; its elapsed time includes plotting and export.
